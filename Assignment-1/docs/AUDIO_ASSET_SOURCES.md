# Audio Asset Sources

## Current bundled catalog

All bundled demo audio and covers are generated locally by
`server\scripts\generateDemoAssets.js`. The audio is synthesized from oscillators
and envelopes in source code; the covers are procedurally drawn PNGs. No third-party
recording, sample, stock image, or existing commercial cover is used by these bundled
assets. They are project-generated demonstration fixtures, not licensed music releases.

The first three tracks form the authored segue chain under the implemented 8% tempo
tolerance and Camelot rules: 8A → 9A → 9B, with BPM 100 → 104 → 108. A → B and
B → C pass. A → C is rejected because 8A and 9B are not compatible Camelot keys,
even though their BPM difference is exactly at the 8% limit. These profiles are
synthetic demo metadata, not audio-analysis results. The seed catalog marks them
`demoOnly` and includes that distinction in each track's timeline.

## Generate and seed

From the project root:

```powershell
Set-Location .\server
npm run assets:generate
npm test
node .\seed.js
```

`node .\seed.js` requires a configured `server\.env` and MongoDB. For the five known
legacy seed records, the seed script updates those records to the demo catalog instead
of preserving their old titles/media. It also removes the old named seed copies from
`server\uploads\tracks` and copies in the new WAV/PNG files. Other database records are
not bulk-deleted.
